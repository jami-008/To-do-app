# Todo App

A simple, offline-first todo application built with HTML, CSS, and vanilla JavaScript. Todos are saved in the browser with LocalStorage.

## Features

- Add, edit, and delete todos
- Mark todos as completed or active
- Total, active, and completed counts
- Clear completed todos
- Filter by All / Active / Completed
- Search todos
- Priority and due date
- Empty-state messages
- Responsive layout

## Project structure

```text
todo-app/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── README.md
```

## How to run

Open `index.html` in a browser. No build step or server is required.
